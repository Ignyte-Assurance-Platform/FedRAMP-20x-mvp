# TOC rules

- Heading `## Table of Contents` immediately after the H1 (and after an optional intro paragraph).
- One numbered entry per `##` heading, in order. `###` headings are not listed.
- Anchor = lowercase heading, spaces → `-`, drop everything that is not a letter, digit, space or hyphen. `## 2. What we build` → `#2-what-we-build`.
